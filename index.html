Buku Panduan Penggunaan NusaGIS

🗺️ NusaGIS - RealTime Mapping & GIS

Aplikasi WebGIS modern ini dirancang khusus untuk kebutuhan survei lapangan berbasis GPS/GNSS presisi tinggi (RTK), digitasi spasial, impor/ekspor data GIS, analisis spasial, dan monitoring pengguna secara realtime.

1. Perekaman Titik GNSS/RTK Realtime (Fitur Lapangan)
  • Pastikan GPS/lokasi perangkat menyala.
  • Tombol melayang 🔴 REC akan muncul di pojok kiri bawah layar peta.
  • Ketuk tombol tersebut, isi metadata survei (ID, Tinggi Antena, Keterangan, Solusi RTK).
  • Simpan titik untuk mengirim data secara instan ke cloud database.
2. Menggambar & Digitasi Spasial Manual
  • Gunakan toolbar Leaflet.Geoman di sisi kiri layar untuk menggambar Pin, Polyline, atau Polygon.
  • Fitur Snapping Cerdas akan aktif otomatis ketika kursor mendekati titik batas/sudut gambar lainnya untuk mencegah overlap/tumpang tindih.
3. Impor & Ekspor Data
  • Gunakan menu Tools -> Impor Shapefile (.zip) untuk mengunggah shapefile Anda.
  • Unduh data kapan saja dalam format Excel (.xlsx), Shapefile (.shp), atau GeoJSON (.geojson) melalui panel Sidebar.
4. Dashboard Admin & SQL Spasial (Khusus Admin)
  • Klik Dashboard Admin di kanan atas jika Anda masuk dengan akun Admin (e.g. admin@gmail.com).
  • Pantau Surveyor secara realtime pada Live Radar Map, atur lisensi, dan jalankan perintah query PostGIS di SQL Console.
